# Sustainable Development Goal Alignment

## Assessment

**Potential, indirect alignment only:** UN Sustainable Development Goal 9, Target 9.5. The target concerns enhancing scientific research and technological capabilities, including research and development workers and spending. Its indicators measure R&D expenditure as a share of GDP and researchers per million people. See the [official UN Goal 9 targets and indicators](https://sdgs.un.org/goals/goal9#targets_and_indicators).

SPECTRA-32 provides an open, low-cost embedded-security software prototype, research protocols, and a future ESP32 reference path. These could support learning or research capacity if people use them in documented studies or education. The repository currently demonstrates code and documentation only; it has no adoption, learner, institutional, workforce, spending, or societal-outcome data.

| Assessment item | Evidence and limit |
|---|---|
| SDG / target | SDG 9, Target 9.5: enhance scientific research and technological capability |
| Technical contribution | A session-local IoT security model, a separate virtual node, open experiment protocols, and an ESP-IDF source path intended for future validation |
| Demonstrated impact | None measured. The repository's existence is not evidence of improved research capacity or development outcomes. |
| Potential societal impact | Could reduce setup cost for small-scale IoT security education or exploratory research if adopted and maintained; this is a hypothesis, not a result. |
| Possible project indicators | External contributors; documented course/research uses; reproducible external replications; maintained hardware/firmware variants; published run records. These are project adoption measures, not UN SDG indicators. |
| UN indicator relationship | The project does not measure or claim changes to R&D expenditure (9.5.1) or researchers per million people (9.5.2). |
| Limitations | No studies, deployment data, user evidence, or impact evaluation; the board behavior is partly simulated; hardware and security experiments are unverified. |

No other SDG alignment is claimed. The project should not add stronger SDG language unless it collects independent evidence of use and outcomes.
