# SPECTRA-32 v0.2.1 — Release Provenance Update

This patch release improves the traceability of SPECTRA-32's Python model and classic ESP32 firmware build.

## Improved

- Release packaging now verifies and attaches the exact ESP-IDF Component Manager dependency lock produced by the tagged firmware build.
- `release-manifest.json` records the firmware lock digest, build target, ESP-IDF version, and the lock's coverage boundary.
- `SHA256SUMS.txt` covers the runtime SBOM, firmware dependency lock, and provenance manifest.
- GitHub Secret Scanning and push protection are enabled for the public repository.

## Verification

The Python quality workflow validates and uploads the version-matched CycloneDX 1.5 runtime SBOM. The ESP-IDF workflow builds the classic `esp32` target and uploads its generated component lock. Exact-tag run links and source commit are recorded in the release manifest.

## Limits

The ESP-IDF Component Manager lock does not include built-in ESP-IDF components or compiler/toolchain binaries, so it is not a complete firmware SBOM. No physical ESP32 run or security experiment is included. Streamlit remains a behavioral software model.
