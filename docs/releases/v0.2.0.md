# SPECTRA-32 v0.2.0

Dashboard and verification refinement release for the VIGIL-IoT SPECTRA-32 research prototype.

## Added and improved

- Added loopback Mosquitto integration coverage for the Python node's MQTT ON/OFF command and status flow, invalid-payload rejection, and state counters.
- Made the MQTT invalid-command assertion deterministic using same-publisher message ordering.
- Improved the session counter chart's zero baseline, sample markers, and time labels.
- Aligned the dashboard and board illustration with the documented VIGIL-IoT visual system, using locally bundled licensed fonts.
- Attached a version-matched CycloneDX 1.5 runtime SBOM, checksum, and source/CI manifest to the GitHub Release.

## Verification

- Exact-tag Python 3.12–3.14 matrix and loopback MQTT integration: [workflow run 41323154657](https://github.com/VIGIL-IoT/VIGIL-Spectra-32/actions/runs/41323154657).
- Exact-tag ESP-IDF 6.1 classic ESP32 build: [workflow run 41323154363](https://github.com/VIGIL-IoT/VIGIL-Spectra-32/actions/runs/41323154363).
- The release includes a version-matched CycloneDX 1.5 runtime SBOM, checksum file, and provenance manifest with the exact source commit and workflow run IDs.

## Limits

This release still has no physical-board or hardware-in-loop validation and contains no completed security experiment. Dashboard scenarios remain a deterministic software model and do not send traffic to the node or a physical device.
