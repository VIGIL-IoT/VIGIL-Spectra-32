# SPECTRA-32 v0.1.0

Initial tagged release of the VIGIL-IoT SPECTRA-32 research prototype. This release points to source commit `58ba1f7861b7fea6c8be2d529720f4f9584f9c7c`.

## Included

- Streamlit session-local behavior model with a representative ESP32 DevKit board, scenario controls, counters, and event records.
- Explicit host-side USB discovery and classic ESP32 chip identification.
- Separate Python node with loopback HTTP and optional MQTT behavior.
- Vulnerable classic ESP32 reference firmware and an ESP-IDF 6.1 build workflow.
- Research protocols, system architecture, safety boundaries, requirements, traceability, and repository audit.
- Python 3.12–3.14 quality workflow and CycloneDX 1.5 runtime SBOM generation.

## Verification

- Exact-tag Python quality matrix and runtime SBOM: [workflow run 41323154451](https://github.com/VIGIL-IoT/VIGIL-Spectra-32/actions/runs/41323154451).
- Exact-tag ESP-IDF 6.1 classic ESP32 build: [workflow run 41323154494](https://github.com/VIGIL-IoT/VIGIL-Spectra-32/actions/runs/41323154494).
- The release includes a version-matched CycloneDX 1.5 runtime SBOM, checksum file, and provenance manifest.

## Limits

The Streamlit dashboard is not connected to the standalone node or physical device. No physical ESP32 validation, security experiment, or measured result is included. Use the vulnerable firmware only on owned hardware in an isolated lab.
